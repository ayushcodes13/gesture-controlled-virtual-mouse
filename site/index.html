BEFORE YOU RUN IT

Built for a local desktop.

  • Python 3.9+ with project dependencies installed
  • A webcam and an interactive graphical desktop
  • Camera access; on macOS, Accessibility permission for pointer control
  • The hand-landmarker model downloaded by the provided script
◎

LOCAL PROCESSING

Frames stay on your machine.

The project code processes webcam frames locally. Desktop actions are disabled until you press t in the camera window. Press q to exit. This static page has no webcam access, API, or gesture simulator.
